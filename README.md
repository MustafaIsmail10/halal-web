# Halal Web is a Chrome extension that helps you avoid distractions while browsing the web. It blocks access to certain websites and provides a simple interface for managing your browsing habits.

## 1. Features

### 1.1 GrayScale Mode

Halal Web includes a GrayScale mode that turns the colors of websites into shades of gray. This feature is designed to reduce the visual appeal of websites and help users focus on their tasks.

When enabled, the GrayScale mode will apply a CSS filter to the entire webpage, making it appear in grayscale. It can be disabled at a specific site by clicking the extension icon and toggling the GrayScale mode off. Reloading the page will restore grayscale.
